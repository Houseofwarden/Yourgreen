# Yourgreen

Yourgreen is a simple plant and gardening website created for our CSE326 Internet Programming project at Lovely Professional University.

## Features

- Indoor plant catalogue with pictures, descriptions and prices
- Plant accessories catalogue
- Basic plant care tips
- Navigation between sections of the website

## Technologies

- HTML: page structure and content
- CSS: colors, layout and styling

## Run the project

Open `index.html` in any web browser.
